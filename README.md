# My Amazon Product Card Experiment 👟

Hey there! This is a quick front-end practice project where I built a replica of an Amazon product details section. I wanted to see how closely I could match real e-commerce styles using just raw HTML and CSS.

## 🤔 What I Worked On
- **Button Replicas:** I spent time matching the exact look of Amazon's famous yellow "Add to Cart" and orange "Buy Now" buttons, down to the rounded pill shapes.
- **Accurate Colors:** I sourced the specific shades of green for the "In Stock" notification and blue for the "Back to Amazon" link to make it feel authentic.
- **Clean Structure:** Kept the code simple and easy to read.

## 🛠️ Built With
- **HTML5** for the text, links, and buttons.
- **CSS3** for all the custom fonts, sizing, margins, and colors.

## 🚀 How to Look at It
1. Download the code or clone this repository.
2. Find the file (usually `index.html`) on your computer.
3. Double-click it to open it up right in your web browser!
